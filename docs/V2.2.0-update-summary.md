# SafeBox V2.2.0 更新摘要

V2.2.0 聚焦登录体验、界面主题和布局细节，让 SafeBox 日常打开更快、错误反馈更清楚，页面工具栏也更顺手。

## 主要更新

- 登录页新增“记住密码”选项。
- 记住的保险箱密码使用 Windows 当前用户 DPAPI 加密保存，用于本机快速登录。
- 密码错误、信息不完整等登录失败场景会同时显示页面提示和顶部悬浮提醒。
- 设置页新增主题选择：保留“经典”主题，并新增 Linear Dark 深色主题。
- 登录窗口改为更舒展的主窗口内布局。
- 账号密码页和小纸条页顶部工具栏统一为紧凑排版。
- 回收站与设置固定到底部管理区，不再和功能模块挤在一起。

## 修复与优化

- 修复登录错误提示被隐藏后“看起来没反应”的问题。
- 修复排序标签与下拉框间距过大的显示问题。
- 修复登录页空提示栏占位导致的异常空白。
- 补充登录、主题、排序和保险箱配置相关回归测试。

## 版本

- 项目版本号更新为 `2.2.0`。
