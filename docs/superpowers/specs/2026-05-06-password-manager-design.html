Windows 11 Fluent · 本地离线优先

一个给自己用的密码和私密记录管理器

这个软件不是只保存网站密码，而是一个本地个人保险箱。它可以保存账号密码、安全小纸条、临时文字、公众号或小程序入口说明。第一版重点是电脑端好用、安全、像 Windows 11 原生应用。

记录字段

不强迫每条记录都必须是网站。公众号、学校平台、小程序、软件后台都可以自然保存。

字段 意思 例子 是否必填
名称 这条记录叫什么 学校二课平台、Steam、校园网 必填
账号 登录时用的手机号、邮箱、学号或用户名 2024xxxx、手机号、邮箱 必填
密码 对应的密码，可以显示、隐藏、复制 保存为加密内容 必填
分类 大的整理方式 学校、游戏、生活、软件、工作 可选
标签 更细的标记 公众号、常用、重要、临时 可选
备注 补充说明 从学校公众号菜单进入 可选
网址或入口说明 有网址就填网址，没有网址就写怎么打开 微信公众号、App 内入口、小程序名称 可选

安全设计

文档里用直白说法描述安全功能，避免把使用者困在专业名词里。

使用体验

  • 打开软件时输入一个总密码，就像打开保险箱的钥匙。
  • 离开一段时间后自动锁住，再回来需要重新输入总密码。
  • 复制密码后，过一小会自动清空剪贴板。
  • 删除、导出、查看隐藏密码这类操作需要二次确认。

技术原则

  • 所有数据只保存在本机，不默认联网。
  • 本地数据库整体加密，不能直接打开文件看到明文。
  • 总密码不直接保存，只保存用于校验的安全信息。
  • 备份文件也必须加密，避免复制出去后泄露。

手机快传设计

它解决的是“手机上的文字想发到电脑保存”的问题，不做完整聊天软件。

1

电脑开启接收

在软件里点“手机快传”，电脑端临时开启局域网接收页面。

2

手机扫码

手机浏览器打开一个简单页面，不需要先做手机 App。

3

发送文字

粘贴公众号内容、链接、验证码说明、临时账号等文字。

4

进入收件箱

电脑收到后保存到收件箱，可以再转成账号记录或安全小纸条。

技术路线

正式软件使用 Python + PySide6 / Qt。HTML 只用于现在讨论和预览，不作为最终界面技术。

桌面端

  • Python 作为主要开发语言。
  • PySide6 / Qt 负责窗口、动画、表单、列表、系统托盘。
  • 界面样式模仿 Windows 11 Fluent 的圆角、浅色、柔和阴影和轻动效。
  • 本地数据建议使用 SQLite 文件，再叠加加密层。

推荐模块

  • vault 数据保存、读取、加密。
  • ui PySide6 页面和组件。
  • security 总密码、自动锁定、剪贴板清理。
  • inbox 安全小纸条和后续手机快传。
  • backup 导入、导出、备份恢复。

下一步讨论点
